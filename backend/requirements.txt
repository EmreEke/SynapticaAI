# ============================================
# KURULUM TALİMATLARI
# ============================================
# 
# 1. Python 3.10+ yüklü olduğundan emin olun
# 2. Virtual environment oluşturun: python -m venv venv
# 3. Virtual environment'ı aktifleştirin:
#    - Windows: venv\Scripts\activate
#    - Linux/Mac: source venv/bin/activate
# 4. Bağımlılıkları yükleyin: pip install -r requirements.txt
# 
# 5. SpaCy Modeli İndirin (Türkçe veya İngilizce):
#    - Türkçe: python -m spacy download tr_core_news_tr
#    - İngilizce: python -m spacy download en_core_web_sm
# 
# 6. .env dosyası oluşturun ve gerekli değişkenleri ekleyin:
#    - SECRET_KEY=your_secret_key_here
#    - GEMINI_API_KEY=your_gemini_api_key_here
#    - DATABASE_URL=postgresql://user:password@localhost/dbname
# 
# 7. Veritabanını oluşturun ve migrate edin
# 8. Sunucuyu başlatın: uvicorn main:app --reload
